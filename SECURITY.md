# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | -------------------- |
| latest  | :white_check_mark:   |

## Reporting a Vulnerability

If you discover a security vulnerability in Kisan Mitra, please report it responsibly.

**Do not** open a public GitHub issue for security problems.

Instead, email the maintainers or open a [private security advisory](https://github.com/Dasarigalla-Raviteja/kisanmitra/security/advisories/new) on GitHub.

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if you have one)

We aim to acknowledge reports within 48 hours and provide an initial assessment within 7 days.

## Security Practices

- Never commit `.env` files or API keys
- Rotate credentials if they are accidentally exposed
- Use environment variables for all secrets in development and production
